# 计算机教室签到与后台管理系统

一个前后端整合后的机房使用记录系统：学生端用于签到，后台端用于记录管理与数据维护。  
服务端仅依赖 Node.js（无 Python、无 npm 第三方包）。

## 1. 功能概览

- 学生签到（适合中小学生使用）
  - 学期 / 周次 / 班级 / 学生姓名 / 学习内容 / 机器情况 / 教师
- 后台管理
  - 记录筛选、删除、CSV 导出
  - 学期与班级新增 / 删除
  - 教师名单导入
  - 学习内容导入
  - 签到记录 CSV 导入（追加 / 覆盖）
- 数据持久化
  - 本地文件：`data/db.json`

## 2. 运行要求

- 仅需安装 **Node.js**
- 不需要安装 Python
- 不需要安装任何 npm 第三方依赖

## 3. 启动方式（Windows 推荐）

双击运行：

```bat
start.bat
```

或命令行：

```bash
node server.js
```

启动后访问（默认端口 `3000`）：

- 本机：`http://127.0.0.1:3000`
- 局域网：`http://<你的IP>:3000`

### 后台登录验证

- 后台登录页：`http://127.0.0.1:3000/admin/login`
- 后台管理页：`http://127.0.0.1:3000/admin`（未登录会自动跳转到登录页）
- 默认账号密码：
  - 账号：`admin`
  - 密码：`admin123`
- 可通过环境变量覆盖后台账号密码：

```bash
ADMIN_USERNAME=your_admin ADMIN_PASSWORD=your_password node server.js
```

## 4. CSV 导入说明

### 4.1 签到记录 CSV（中文表头）

```text
学期,周次,班级,学生姓名,学习内容,机器情况,授课教师
```

### 4.2 教师导入（文本）

在页面中每行输入 1 位教师姓名即可导入。

### 4.3 学习内容导入（文本）

选择目标学期后，每行输入 1 条学习内容即可导入。
