# 马桥镇陈庄小学计算机教室学生签到程序

一个可在局域网使用的学生签到系统，服务端仅需安装 Node.js 即可运行（无第三方依赖）。

## 功能说明

- 局域网访问：服务监听 `0.0.0.0`，同网段设备可通过 IP 访问。
- 签到字段：学期、周次、班级、学生姓名、学习内容、机器情况、授课教师。
- 数据持久化：自动保存到 `data/db.json`。
- 数据导入：
  - 教师名单导入（每行一个）
  - 一学期教学内容导入（每行一个）
  - 签到记录 CSV 导入（支持追加 / 覆盖）
- 查询与展示：支持按学期、周次、班级、学生姓名筛选。

## 运行环境

- Node.js 12+（为兼容 Win7，建议使用 Node.js 12.x/14.x）
- 操作系统：Windows 7 / Windows 10 / Linux 均可

> 本项目不依赖 npm 第三方包，下载后可直接运行。

## 启动方式

### Windows（推荐）

双击运行：

```bat
start.bat
```

### 命令行

```bash
node server.js
```

服务启动后会在控制台显示访问地址，例如：

- 本机访问：`http://127.0.0.1:3000`
- 局域网访问：`http://192.168.x.x:3000`

## CSV 导入格式

CSV 第一行表头必须为：

```text
学期,周次,班级,学生姓名,学习内容,机器情况,授课教师
```

示例：

```text
学期,周次,班级,学生姓名,学习内容,机器情况,授课教师
2025-2026第一学期,1,三年级一班,张三,第1周：机房规则与计算机基础认知,正常,王老师
```

## 默认选项

- 学期默认值：`2025-2026第一学期`
- 周次：`1 - 30`
- 班级：
  - 三年级一班
  - 三年级二班
  - 四年级一班
  - 四年级二班
  - 五年级一班
  - 五年级二班
- 机器情况：`正常` / `不正常`
- 默认内置 1 个学期的 30 周教学内容（可在页面重新导入覆盖）
